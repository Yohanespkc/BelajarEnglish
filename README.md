# 🦉 LingoMaster - Belajar Bahasa Inggris Interaktif & AI Tutor

Platform pembelajaran Bahasa Inggris modern, interaktif, dan gamified yang dilengkapi dengan asisten linguistik, studio pelafalan dual-waveform, AI simulator percakapan, dan laporan perkembangan belajar real-time.

🌐 **Demo Web Publik (GitHub Pages)**: [https://yohanespkc.github.io/BelajarEnglish/](https://yohanespkc.github.io/BelajarEnglish/)

---

## ✨ Fitur Unggulan

1. **✍️ AI English Editor**:
   - Analisis teks bahasa Inggris: *fluency*, *vocabulary enhancement*, dan *tone adjustment*.
   - Diff perbaikan kata (*added/removed*) dan penjelasan gramatikal interaktif.

2. **📚 Tanya Kata & Grammar (English Linguistics Tutor)**:
   - Analisis mendalam kosakata: IPA phonetic, definisi semantik (denotasi vs konotasi).
   - **Etimologi & Asal-usul Kata**: Sejarah akar kata (*Proto-Germanic*, *Latin*, *Old English*) dan **sebaran bahasa modern yang banyak menggunakannya saat ini (*Modern Languages & Cognates*)**.
   - Morfologi (*Word Family*), idiom populer, bahasa gaul (*slang* modern), dan nuansa sinonim.

3. **🎙️ Pronunciation Studio (Dual Waveform Comparison)**:
   - Evaluasi pelafalan dengan 3 tingkatan: **Per Kata**, **Kalimat Pendek**, dan **Kalimat Panjang**.
   - Visualisasi perbandingan frekuensi gelombang suara: *Native Audio Waveform* vs *User Recording Waveform*.
   - Skor akurasi pelafalan real-time menggunakan Web Speech API dan AudioContext analyzer.

4. **🗺️ Interactive Learning Path & Gamification**:
   - Jalur belajar terstruktur (*Beginner*, *Intermediate*, *Advanced*).
   - Sistem Hati (*Hearts*), Permata (*Gems*), Streak Harian, dan Toko (*Shop*).
   - Permainan kilat kata *Match Madness* dengan timer dinamis dan combo multiplier.

5. **📊 Profil & Progress Report**:
   - Laporan jejak aktivitas belajar per sesi (*Activity Logger*).
   - Statistik riwayat belajar, akumulasi XP, dan pencapaian medali (*Achievements*).

## 📌 Cara Menyematkan (Embed) ke Google Sites

Anda dapat menampilkan seluruh aplikasi LingoMaster ini secara langsung di dalam Google Sites Anda:

1. Buka [Google Sites](https://sites.google.com/) dan pilih halaman yang ingin disematkan aplikasi.
2. Pada panel menu sebelah kanan, klik **Sematkan** (*Embed*).
3. Pilih tab **Berdasarkan URL** (*By URL*).
4. Masukkan tautan web publik:
   ```text
   https://yohanespkc.github.io/BelajarEnglish/
   ```
5. Klik **Sisipkan** (*Insert*).
6. Tarik sudut kotak sematan untuk menyesuaikan lebar dan tinggi tampilan agar memenuhi layar dengan nyaman.
7. Klik **Publikasikan** (*Publish*) di Google Sites. Aplikasi siap dimainkan oleh siapapun!

## 🚀 Menjalankan Secara Lokal

```bash
# Clone repository
git clone https://github.com/Yohanespkc/BelajarEnglish.git

# Install dependencies
npm install

# Jalankan server pengembangan
npm run dev
```

Buka browser di `http://localhost:6000` (atau mirror Chrome di `http://localhost:6006`).
